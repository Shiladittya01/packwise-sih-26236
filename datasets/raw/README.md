# Raw research datasets

No external recommendation dataset is copied here. The public datasets reviewed are catalogued in [`../../docs/research_sources.json`](../../docs/research_sources.json). They contain food composition, package properties, shelf-life results, or research annotations, but no verified ground-truth table matching all requested food/condition inputs to an experimentally selected material. The prototype training data is generated reproducibly from documented literature-derived design rules instead.

Food composition anchors and tomato respiration values are small, explicitly attributed references in the generator. They are not experimental packaging recommendations.
